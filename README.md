Tienda en linea desarrollada con Django 

Funcionalidades:
Registro y autenticación de usuarios
Categorias de productos
Buscador de productos
Oedenes de usuario
Carrito de compras
Direcciones

El sistema permite agregar productos al carrito antes de que el usuario se registre, 
una vez registrado el ssitema redirijira al usuario a los productos en el carrito donde puede proceder con el pago

validaciones de seguridad, mensajes de feedback, rol superadmin y usuario
